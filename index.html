Figure 3 The SAM 2 architecture. For a given frame, the segmentation prediction is conditioned on the current prompt and/or on previously observed memories. Videos are processed in a streaming fashion with frames being consumed one at a time by the image encoder, and cross-attended to memories of the target object from previous frames. The mask decoder, which optionally also takes input prompts, predicts the segmentation mask for that frame. Finally, a memory encoder transforms the prediction and image encoder embeddings (not shown in the figure) for use in future frames.

Image encoder. For real-time processing of arbitrarily long videos, we take a streaming approach, consuming video frames as they become available. The image encoder is only run once for the entire interaction and its role is to provide unconditioned tokens (feature embeddings) representing each frame. We use an MAE (He et al., 2022) pre-trained Hiera (Ryali et al., 2023; Bolya et al., 2023) image encoder, which is hierarchical, allowing us to use multiscale features during decoding.

Memory attention. To condition the image embeddings on relevant target-object memories, we use a transformer block with q-channel attention (not kv-attention). The key and value tensors are the set of memory embeddings, and the queries are the current-frame image embeddings. This design allows the memory bank to be arbitrarily large without scaling the computational cost quadratically.

Mask decoder. The mask decoder uses a two-way transformer to decode image embeddings and prompt tokens into a mask. It iteratively updates masks via self-attention and cross-attention, and uses a lightweight head to produce the final mask. Masks are upscaled to the original resolution using transposed convolutions.

Memory encoder. After each frame prediction, the memory encoder produces a memory embedding from the current frame's segmentation mask and image encoder features. This embedding is then stored in a memory bank for use in subsequent frames. The memory encoder uses a lightweight CNN to compress spatial information.

会话 总结

这篇论文介绍了Segment Anything Model 2 (SAM 2)，这是一个用于图像和视频中可提示视觉分割的基础模型。

研究背景：

  • 问题：尽管SA模型在图像分割方面取得了显著进展，但视频分割仍面临挑战。
  • 难点：处理低质量视频、高效处理大量帧以及实体的复杂运动和外观变化。
  • 相关工作：现有方法在处理"视频中任何对象的任意分割"方面存在不足。

SAM 2 包含四个核心模块：

Image Encoder
使用 MAE 预训练的 Hiera 图像编码器，为每一帧提供无条件 token。
Memory Attention
使用 q-channel 注意力将当前帧特征与历史记忆关联，支持任意大小的记忆库。
Mask Decoder
双向 Transformer 解码器，通过转置卷积上采样生成最终分割掩码。
Memory Encoder
轻量级 CNN，将分割掩码和图像特征压缩为记忆嵌入，存入记忆库。
